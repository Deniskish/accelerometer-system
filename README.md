# Accelerometer TCP System

Распределённая система обработки данных акселерометра на C++ под Linux.

Реализован вариант **Linux-only**: узлы A и B запускаются как отдельные процессы на Linux, данные акселерометра эмулируются в узле A. Реализован **Уровень 1: TCP-сокеты + JSON**.

## Архитектура

В системе используются три процесса:

`node_a` — отправитель данных акселерометра;
`server` — промежуточный сервер, выполняющий фильтрацию и маршрутизацию;
`node_b` — обработчик данных, вычисляющий модуль ускорения.

Схема обмена:

```text
Node A -> Server -> Node B -> Server -> Node A
```

## Реализованный поток данных

1. `node_a` генерирует эмулированные данные акселерометра с заданной частотой.
2. Пакет содержит поля `version`, `timestamp`, `x`, `y`, `z`.
3. `node_a` отправляет JSON-сообщение на `server` через TCP.
4. `server` отбрасывает подряд идущие дубликаты по `x`, `y`, `z` с точностью до 3 знаков после запятой.
5. Валидный пакет пересылается на `node_b`.
6. `node_b` вычисляет модуль ускорения: `sqrt(x*x + y*y + z*z)`.
7. `node_b` отправляет результат обратно на `server`.
8. `server` пересылает результат на `node_a`.
9. `node_a` записывает результат в файл `accel_module.log`.

## Формат сообщений

Каждое JSON-сообщение завершается символом новой строки `\n`.

Пакет акселерометра:

```json
{
  "version": 1,
  "timestamp": 1712938123456,
  "x": 0.123,
  "y": 9.807,
  "z": 0.045
}
```

Результат вычисления модуля:

```json
{
  "version": 1,
  "timestamp": 1712938123456,
  "module": 9.808
}
```

Поле `version` добавлено для базовой поддержки версионирования протокола. В текущей реализации используется версия `1`.

## Сборка

Требования:

Linux;
CMake 3.16+;
компилятор с поддержкой C++17.

Команды сборки:

```bash
cmake -S . -B build
cmake --build build
```

После сборки будут созданы три исполняемых файла:

```text
build/server
build/node_a
build/node_b
```

## Запуск

Нужно открыть три терминала.

### Терминал 1 — сервер

```bash
./build/server 127.0.0.1 9000 9001
```

Где:

`9000` — порт для подключения `node_a`;
`9001` — порт для подключения `node_b`.

### Терминал 2 — Node A

```bash
./build/node_a 127.0.0.1 9000 50 accel_module.log
```

Где:

`127.0.0.1` — адрес сервера;
`9000` — порт сервера для `node_a`;
`50` — частота генерации данных, Гц;
`accel_module.log` — файл для записи результата.

### Терминал 3 — Node B

```bash
./build/node_b 127.0.0.1 9001
```

Где:

`127.0.0.1` — адрес сервера;
`9001` — порт сервера для `node_b`.

## Проверка результата

После запуска `node_a` создаёт файл:

```text
accel_module.log
```

## Выбор формата сериализации

Для Уровня 1 выбран JSON, потому что он указан в задании как базовый формат и удобен для отладки: сообщения можно читать в логах без дополнительных инструментов.

## Ограничения реализации
